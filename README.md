# Shreya Cloud Kitchen — Food Delivery MVP

Flutter starter project for a customer-side food ordering app.

## Included
- Home/menu
- Food items and prices
- Cart
- Quantity controls
- Checkout
- Delivery address
- Payment-request UI
- Admin notification placeholder

## To make it production-ready
1. Add Firebase Authentication/Firestore.
2. Add Firebase Cloud Messaging for admin/customer push notifications.
3. Connect a compliant Indian payment gateway (for example Razorpay/Cashfree/PhonePe PG) and verify payments server-side using webhooks.
4. Add an Admin Flutter/Web dashboard.
5. Add real order status and delivery-partner tracking.
6. Configure Android signing and build the release APK.

This project intentionally does not contain real merchant credentials or hard-coded payment secrets.
